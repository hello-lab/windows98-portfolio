# 🖥️ Windows 98 Themed Showcase Website

**My First Proper Website** — built as a fun tribute to the classic Windows 98 UI.

---

## 📑 About

A nostalgic, pixel-perfect Windows 98 themed showcase website created entirely with **Vanilla JavaScript**. No fancy frameworks, no bloated front-end libraries — just pure HTML, CSS, and JS, like it's 1998 again.

The only libraries I used on the backend are:

- **Express-Session** 🗂️ — for session management  
- **SpeakEasy** 🔐 — for generating TOTP authenticator codes  

Everything else is handcrafted.

---

## 📺 Features

- 🎨 **Windows 98-inspired UI & animations**
- 📝 **Vanilla JS** front-end interactions
- 🗂️ Session storage with **Express-Session**
- 🔐 TOTP-based login authentication with **SpeakEasy**
- 📦 Lightweight, clean, and nostalgia-inducing

---

## 🚀 Tech Stack

- **Front-end:** HTML, CSS, Vanilla JavaScript  
- **Back-end:** Node.js, Express.js  
- **Libraries:**  
  - `express-session`  
  - `speakeasy`
